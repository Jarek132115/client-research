# Outcomes ledger — the accountability + learning layer

The routine finds and qualifies; only you know what got replies. Log every contact
here. Weekly, a Claude session reads this and rewrites digest.md + sources.md + the
routine prompt to do more of what worked.

## How to log (10 seconds per prospect contacted)
`YYYY-MM-DD | Brand | vertical | channel | style (teardown/demo-offer) | outcome`
Outcomes: no-reply · opened · replied-cold · replied-interested · call-booked · bounced · closed-won · closed-lost

## What the weekly review answers
1. Which vertical has the best reply rate? (daily rotation collects this)
2. Which opener wins — teardown vs demo-offer?
3. Which weakness-lead pulls the best replies?
4. Which discovery source produced converting prospects? (update sources.md)
5. Were revenue estimates roughly right on calls? (calibrate if off)
6. Did any email pattern guesses bounce? (tighten the logic)
